# Task System - Quick Reference

## API Endpoints Quick Reference

### Basic CRUD
```bash
# Get all tasks
GET /api/v1/tasks

# Get task by ID
GET /api/v1/tasks/:id

# Create task
POST /api/v1/tasks

# Update task
PATCH /api/v1/tasks/:id

# Delete task
DELETE /api/v1/tasks/:id
```

### Bulk Operations
```bash
POST /api/v1/tasks/bulk/create
PATCH /api/v1/tasks/bulk/update
DELETE /api/v1/tasks/bulk/delete
```

### Status Operations
```bash
POST /api/v1/tasks/:id/complete
POST /api/v1/tasks/:id/skip
```

### AI Features
```bash
POST /api/v1/tasks/ai/generate-from-goals
POST /api/v1/tasks/ai/generate-daily
POST /api/v1/tasks/:id/breakdown
POST /api/v1/tasks/ai/magic-sync
```

### Analytics
```bash
GET /api/v1/tasks/analytics/stats
GET /api/v1/tasks/analytics/productivity
GET /api/v1/tasks/analytics/patterns
GET /api/v1/tasks/special/overdue
GET /api/v1/tasks/special/today
```

## Task Statuses

| Status | Description |
|--------|-------------|
| `TODO` | Task not started |
| `IN_PROGRESS` | Task being worked on |
| `COMPLETED` | Task finished |
| `CANCELED` | Task canceled |
| `SKIPPED` | Task skipped (tracked for patterns) |

---

## Task Priorities

| Priority | Usage | Color Coding |
|----------|-------|--------------|
| `URGENT` | Critical, time-sensitive | Red |
| `HIGH` | Important, high priority | Orange |
| `MEDIUM` | Normal priority | Yellow |
| `LOW` | Can wait, low priority | Green |

---

## Task Sources

| Source | Description |
|--------|-------------|
| `AI_GENERATED` | Generated by AI from user data |
| `MANUAL` | Manually created by user |
| `FROM_GOAL` | Derived from a specific goal |
| `FROM_HABIT` | Created from habit tracking |
| `FROM_PLAN` | Part of a daily/weekly/monthly plan |

---

## Categories

- `HEALTH` - Health-related tasks
- `FITNESS` - Exercise and physical activity
- `HABITS` - Habit building tasks
- `MONEY` - Financial tasks
- `CAREER` - Work and career tasks
- `RELATIONSHIPS` - Social and relationship tasks
- `PRODUCTIVITY` - General productivity tasks
- `ROUTINES` - Daily routines
- `PERSONAL_GROWTH` - Self-improvement
- `LEARNING` - Educational tasks
- `OTHER` - Miscellaneous

  "priority": "HIGH",

## Important Notes

1. **All endpoints require authentication** - Include Bearer token
2. **AI operations may take 3-10 seconds** - Show loading states
3. **Rate limit AI endpoints** - Prevent token abuse
4. **Tasks auto-link to plans** - When created from plan context
5. **Streaks update automatically** - On task completion
6. **Notifications respect user settings** - Check preferences
